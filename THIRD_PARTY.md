# Third-party software and data: licences and required credits

This pipeline is for use inside the firm. It runs open-source software and
public data, and each comes with conditions. This page lists them, says what
every client output must carry, and says what would need a review before the
software leaves the firm.

The credit lines in client outputs are generated by `credits.py` from what each
run actually used. The wording lives there and nowhere else. This page quotes
it; if the two ever differ, `credits.py` is what the outputs say. The software
citations in `credits.py` were written from memory on 5 Oct 2026; the 7 Oct
2026 trust review checked them against the publishers and corrected them
(MiaplPy volume 171 and title, the three snaphu papers, the MIDAS paper, the
Copernicus DEM licence notices and the ASF DAAC line). Optional and not yet
added: USGS's requested basemap wording ("Map services and data available from
U.S. Geological Survey, National Geospatial Program.").

## In one paragraph

Inside the firm, nothing here restricts how we run the software or use its
results for paid work. Client reports, rasters and KMZs are outputs, not copies
of the software, so the software licences put no conditions on them. The DATA
licences do: Sentinel-1, ERA5, the Copernicus DEM, the GNSS stations and the
other sources below must be credited wherever their results are shown, and the
pipeline prints those credits for you. The software itself must not be given
to anyone outside the firm (client, partner, contractor) without a licence
review: it imports GPL-3 code (MintPy, MiaplPy with our patch, PyAPS3, PySolid).

## Data the pipeline uses but does not credit automatically

- **Precise orbits** (Copernicus POD), fetched with `sentineleof`, are part of
  the Copernicus Sentinel data and covered by its notice.
- **IGS global ionosphere maps**, fetched by MintPy's `iono_tec.py` from NASA
  CDDIS with the Earthdata login. Used only for large areas
  (`ionosphere_correction: auto`). Not credited by `credits.py`; add a line if a
  large-area report goes out.
- **OpenStreetMap Nominatim** answers the builder's place search and gives the
  report its place name ("Gibson County, Indiana"). Nominatim's usage policy
  asks for at most one request per second and an identifying contact; the
  pipeline sends the firm and contact set with `insar doctor --firm ...
  --contact ...`. Never type a client's or a site's name into the search.

### snaphu and CS2

snaphu's README grants the parts derived from the CS2 minimum-cost-flow solver
(Goldberg and Cherkassky; IG Systems) for "strictly noncommercial purposes",
with any other use needing a commercial licence from IG Systems. The pipeline
never uses CS2: `unwrap_crop.py` writes `INITMETHOD MST`, and doctor's
known-answer test uses MST. So `install/build_snaphu.sh` compiles snaphu with
`-DNO_CS2` and leaves `snaphu_cs2.c` out. A config asking for MCF
initialisation then stops with "program not compiled with cs2 MCF solver
module".

Checked on 6 Oct 2026: the new build and the installed CS2 build give
bit-identical unwrapped phase and connected components on a 600 x 900 DEFO/MST
test pair, and the same residual (2.4e-5 rad) on doctor's known answer.
`install.sh` rebuilds a snaphu 2.0.7 that still contains CS2.

The classic `stack` route's default engine (`stack_unw_engine: isce`) uses the
snaphu 1.4.2 built into ISCE2, which contains the CS2 code. It runs CS2 only
with `initMethod='MCF'`, which topsStack chooses when `stack_unw_full_cost` is
false (the default is true, giving MST). The classic route is for comparison
only; keep `stack_unw_full_cost: true` there.

## Before anything leaves the firm

- **Results** (reports, rasters, KMZ, workbooks, packages): fine, with the
  credits the pipeline prints. Do not remove them.
- **The software** (this folder, a release tarball, a copy of an environment):
  not without a licence review. The GPL-3 parts mean that handing it to a
  client, partner or contractor is a distribution with obligations (source
  for the GPL components and our MiaplPy patch, licence compatibility of the
  pipeline's own code).
- **Builder screenshots**: keep the tile credit; no Esri imagery without an
  Esri licence.
